# CONT-P v0.9

This version adds a local Hardy–Littlewood Euler-factor null for the q=180 vs q=210 contrast and tightens the novelty audit.

Main result: under a simple triplet local-factor variance proxy, prime 7 accounts for 67.18% of unresolved local sieve variance from primes >=7, compared with 80.89% empirical held-out suppression at equal state cardinality. Pair-only local contrast predicts only 47.16%.

Interpretation: local sieve structure plausibly explains a large part of the 7 effect, but not all of it. No equality between the proxy and CMI/log-loss is claimed.

Novelty warning: Daniel John Murray's 2026 SSRN papers substantially overlap the coarse-projection/primorial-recovery thesis. CONT-P novelty is not established and must be restricted to narrower complexity-matched functionals/controls if direct comparison confirms a distinction.
